# F0 — Prueba de concepto (v0)

Objetivo: un altavoz virtual propio que pase audio, instalado y probado en
esta maquina, **sin cambios en la app**.

## Requisitos (todo gratis)

- Visual Studio 2022 Community + workload "Desktop development with C++".
- Windows Driver Kit (WDK) + Windows SDK (misma version).
- Windows en **modo test signing** (`bcdedit /set testsigning on`) con
  Secure Boot desactivado. Marca "Test Mode" en el escritorio; se revierte.

## Pasos

1. **Compilar el sample tal cual** (sanity del entorno):
   `powershell -ExecutionPolicy Bypass -File tools\build.ps1`
2. **Firmar en modo prueba** el paquete generado (certificado de prueba +
   `signtool`/`Inf2Cat`).
3. **Instalar**: `devcon install <inf> Root\<HWID>` (devcon viene con el WDK).
4. **Verificar**: aparece el dispositivo en Configuracion de sonido y su
   `[Loopback]` es visible para WASAPI (pyaudiowpatch).
5. **Probar E2E**: apuntar la app al loopback del dispositivo nuevo y medir
   (huecos, latencia, CPU) frente a VB-Cable.
